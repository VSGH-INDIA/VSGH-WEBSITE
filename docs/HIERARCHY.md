# Governing document hierarchy

```text
LEVEL 0  VSGH Corporate Documentation Baseline
LEVEL 1  VSGH Stage 2 Website Governance
LEVEL 2  WP01 — Website Requirements / Master Specification
LEVEL 3  WP02 — Website Architecture / UX Architecture
LEVEL 4  WP03 Revision B — Approved Technology Baseline
LEVEL 5  WP04 — Frozen UX / Visual Design Requirements Baseline
LEVEL 6  VSGH Cursor AI Website Implementation Governance Rev A
LEVEL 7  Individual implementation tasks
```

A lower-level document shall never override a higher-level approved baseline.

## WP04 freeze meaning

Frozen means the **requirements and governance** for UX, IA (now WEB-081), design principles, components, responsive behavior, accessibility, motion, content/IP, prototype **requirements**, and verification **requirements**.

Frozen does **not** mean the final visual design, final brand tokens, high-fidelity prototype, or production components already exist.
