# VSGH-WEB-041 — Technology Stack Selection Master Specification


> **HISTORICAL / NON-AUTHORITATIVE.** SUPERSEDED by WP03 Revision B. Retain for history. Do not implement from this copy.

## 1. Purpose
Define the decision framework for selecting the VSGH external website technology stack.

## 2. Scope
Covers:
- Frontend
- Application framework
- CMS
- Backend/API
- Database
- Media storage
- Search
- Hosting
- CDN/WAF
- Authentication
- CI/CD
- Monitoring
- Analytics
- Email integrations
- Security tooling

## 3. Selection Principles
The selected stack shall optimize for:
- Security
- Maintainability
- Performance
- Reliability
- Developer productivity
- Accessibility
- Scalability
- Portability
- Vendor independence
- Total cost of ownership
- Long-term supportability

## 4. Domain
Canonical public domain:
**https://www.vsgh.com**

Registrar:
**Hostinger**

The registrar relationship shall not constrain application hosting decisions.

## 5. Decision Rule
No technology shall be selected solely because it is popular, inexpensive, familiar, or bundled with the domain provider.

## 6. Output
The final selection shall be recorded in the approved WP03 technology decision baseline.
