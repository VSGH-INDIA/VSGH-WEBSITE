# VSGH-WEB-046 — Hosting Platform and Compute Selection


> **HISTORICAL / NON-AUTHORITATIVE.** SUPERSEDED by WP03 Revision B. Retain for history. Do not implement from this copy.

## 1. Objective
Select the production hosting model.

## 2. Candidate Models
- Managed application hosting
- Cloud platform
- Container platform
- Virtual server
- Static/edge hosting
- Hybrid model

## 3. Evaluation
Assess:
- Security
- Availability
- Performance
- Deployment control
- Scalability
- Backup
- Recovery
- Monitoring
- Cost
- Vendor lock-in
- Operational burden

## 4. Hostinger
Hostinger is the current domain registrar. Website hosting shall be evaluated independently.

## 5. Decision
The selected hosting model shall support the approved architecture and security boundary.
