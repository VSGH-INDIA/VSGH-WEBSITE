# VSGH-WEB-043 — CMS Selection and Content Platform Evaluation


> **HISTORICAL / NON-AUTHORITATIVE.** SUPERSEDED by WP03 Revision B. Retain for history. Do not implement from this copy.

## 1. Objective
Select a CMS suitable for controlled VSGH public content.

## 2. Requirements
Evaluate:
- Structured content
- Workflow
- Revisions
- RBAC
- MFA compatibility
- Auditability
- API/headless capability
- Preview
- Media management
- Backup/export
- Search
- Localization readiness
- Security
- Vendor lock-in
- Cost

## 3. Architecture Preference
A headless or API-capable CMS may be preferred where it improves security, frontend flexibility, and separation of concerns.

## 4. Prohibition
The CMS shall not become a repository for sensitive engineering IP.
