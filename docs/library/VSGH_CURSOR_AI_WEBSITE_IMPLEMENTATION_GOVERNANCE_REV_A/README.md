# VSGH Cursor AI Website Implementation Governance Package

## Status

**BASELINE — REVISION A**

## Purpose

This package governs how Cursor AI shall implement the VSGH external website.

Cursor is the implementation agent. It is not the architecture, IP, legal, security, brand, or corporate approval authority.

## Core Rule

Cursor shall implement approved requirements and shall escalate conflicts rather than silently changing the VSGH baseline.

## IP Rule

When uncertain whether information, imagery, code, data, or configuration could expose VSGH proprietary information:

**STOP AND ESCALATE.**

## Production Rule

Cursor may prepare and verify production code, but formal production release remains subject to VSGH acceptance gates.
