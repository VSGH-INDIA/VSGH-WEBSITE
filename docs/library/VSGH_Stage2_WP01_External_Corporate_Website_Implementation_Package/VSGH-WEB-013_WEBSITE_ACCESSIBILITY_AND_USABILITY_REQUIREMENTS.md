# VSGH-WEB-013 — Accessibility and Usability Requirements

## 1. Objective
Provide an accessible, understandable, responsive public website.

## 2. Requirements
Address:
- Keyboard navigation
- Logical focus
- Text alternatives
- Form labels
- Error identification
- Readable typography
- Contrast
- Responsive design
- Reduced-motion considerations
- Semantic structure

## 3. Testing
The V1 accessibility conformance target is **WCAG 2.2 AA**. This target is frozen. It shall not be downgraded or left as “select later.”

Accessibility shall be evaluated using automated and manual methods appropriate to WCAG 2.2 AA.

## 4. Usability
Critical tasks shall be tested on representative desktop and mobile devices.
