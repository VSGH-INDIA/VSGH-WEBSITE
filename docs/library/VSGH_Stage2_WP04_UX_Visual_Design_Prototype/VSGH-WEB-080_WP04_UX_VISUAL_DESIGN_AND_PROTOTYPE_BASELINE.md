# VSGH-WEB-080 — WP04 UX, Visual Design & Prototype Baseline

## 0. Freeze distinction (VSGH-CURSOR-TASK-001)

**FROZEN (requirements / governance):**
- UX requirements
- information architecture (V1 sitemap: **WEB-081**)
- design principles
- component requirements
- responsive requirements
- accessibility requirements (WCAG 2.2 AA)
- motion requirements
- content/IP requirements
- prototype requirements
- verification requirements

**NOT YET EXECUTED (do not treat as complete):**
- final visual design
- final brand tokens
- high-fidelity prototype
- production component implementation

This freeze is **not** a statement that the final visual design has been implemented, that a high-fidelity prototype exists, or that brand color/type tokens are approved.

## 1. Purpose

Establish the controlled UX, visual design, component, responsive, content-presentation and prototype baseline for the VSGH external website.

## 2. Required Inputs

- Corporate Documentation Baseline
- WP01 Website Implementation Specifications
- WP02 Website Architecture and Design
- WP03 Approved Technology and Development Baseline
- Approved VSGH brand identity
- Approved public technical claims

## 3. Baseline Deliverables

The approved WP04 baseline shall include:
- Information architecture
- User journeys
- Homepage design
- Page templates
- Design language
- Design tokens
- Typography
- Color system
- Grid/responsive rules
- Component library
- Interaction patterns
- Accessibility design
- Forms UX
- Visual asset rules
- CMS/design mapping
- High-fidelity prototype
- Design verification matrix
- Developer handoff specification

## 4. Technical Constraint

The design shall be implementable using the approved:
**Next.js + React + TypeScript + Tailwind CSS + Sanity + Vercel** architecture.

## 5. IP Constraint

The design shall not require disclosure of proprietary engineering information to communicate VSGH capabilities.

## 6. Baseline Gate

The **requirements** baseline is frozen per §0. Execution of visual design, tokens, and prototype remains subject to:
- Design review
- Technical feasibility review
- Accessibility review
- Content/technical claim review
- IP review
- Prototype verification
- Management approval of the *executed* visual baseline

## 7. Implementation Gate

WEB-080 as a **requirements** freeze does **not** by itself authorize production visual implementation or production release. Page implementation requires a later authorized task. Production release remains a VSGH acceptance decision.
