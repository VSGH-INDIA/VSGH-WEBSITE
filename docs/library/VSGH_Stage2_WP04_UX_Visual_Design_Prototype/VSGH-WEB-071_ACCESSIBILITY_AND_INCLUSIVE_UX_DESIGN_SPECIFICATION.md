# VSGH-WEB-071 — Accessibility and Inclusive UX

## 1. Target

The V1 accessibility target is frozen as **WCAG 2.2 AA**. It shall not be downgraded or left TBD.

## 2. Requirements

Design shall address:
- Keyboard access
- Visible focus
- Semantic headings
- Form labels
- Error identification
- Alternative text
- Color contrast
- Resize/reflow
- Reduced motion
- Screen-reader compatibility
- Accessible navigation

## 3. Content

Accessibility shall include both UI and content structure.

## 4. Verification

Accessibility shall be verified through:
- Automated checks
- Keyboard testing
- Screen-reader testing where appropriate
- Manual review
- Representative-device testing

## 5. Baseline

Accessibility is a release requirement, not a post-launch enhancement.
