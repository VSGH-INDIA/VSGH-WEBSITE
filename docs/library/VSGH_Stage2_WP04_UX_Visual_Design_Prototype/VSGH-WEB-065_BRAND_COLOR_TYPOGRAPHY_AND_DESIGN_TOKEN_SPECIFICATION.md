# VSGH-WEB-065 — Brand, Color, Typography and Design Tokens

> Repository CSS tokens (if any) are **PROVISIONAL — NOT FINAL VSGH BRAND TOKENS**. This specification defines semantic roles. It does not approve hex values, typefaces, or visual identity. Do not invent a final brand in implementation tasks.

## 1. Objective

Define reusable visual tokens rather than page-specific styling.

## 2. Token Categories

- Color
- Typography
- Spacing
- Grid
- Border radius
- Borders
- Shadows
- Motion
- Breakpoints
- Elevation
- Iconography
- Component states

## 3. Color System

The final palette shall be derived from the approved VSGH corporate identity.

Required semantic roles:
- Background
- Surface
- Elevated surface
- Primary text
- Secondary text
- Brand accent
- Action
- Success
- Warning
- Error
- Focus

## 4. Typography

Typography shall provide clear distinction between:
- Display
- H1
- H2
- H3
- Body
- Caption
- Label
- Navigation
- Technical data

## 5. Token Rule

Design tokens shall be implemented centrally so that changes propagate consistently.

## 6. Accessibility

Color and typography shall satisfy approved accessibility contrast and readability requirements.
