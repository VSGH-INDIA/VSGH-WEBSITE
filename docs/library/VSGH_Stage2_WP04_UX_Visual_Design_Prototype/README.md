## Governing Technical Baseline

Next.js 16.2.x + React 19.2.x + TypeScript + Tailwind CSS + Sanity Growth + Vercel Pro + Cloudflare DNS + GitHub Team.

## Design Principle

VSGH shall present as an advanced aerospace-materials technology company with a visual language grounded in engineering precision, materials science, industrial capability and controlled futurism.

## IP Principle

The website shall communicate capability without disclosing proprietary process parameters, trade secrets, sensitive engineering data, unreleased designs, experimental datasets, or confidential customer information.

## Gate / freeze meaning

**FROZEN — REQUIREMENTS BASELINE** (WEB-080 Revision B).

Frozen:
- UX requirements, information architecture (V1 tree now WEB-081), design principles, component requirements, responsive requirements, accessibility (WCAG 2.2 AA), motion requirements, content/IP requirements, prototype *requirements*, verification requirements

**NOT YET EXECUTED:**
- final visual design, final brand tokens, high-fidelity prototype, production component implementation

WEB-080 does not claim that the visual design has been implemented or that brand colors/typefaces are approved.
