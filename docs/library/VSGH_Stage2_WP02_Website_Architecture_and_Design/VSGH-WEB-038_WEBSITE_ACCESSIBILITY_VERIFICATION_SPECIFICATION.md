# VSGH-WEB-038 — Website Accessibility Verification Specification

## 1. Verification
Accessibility shall be assessed through:
- Automated testing
- Keyboard testing
- Screen-reader testing where appropriate
- Manual visual review
- Form/error testing
- Responsive testing

## 2. Areas
Verify:
- Navigation
- Focus
- Headings
- Labels
- Text alternatives
- Contrast
- Forms
- Error messages
- Interactive controls
- Motion
- Responsive behavior

## 3. Standard
The V1 accessibility conformance target is **WCAG 2.2 AA**. This target is frozen and shall not be described as “select later,” “TBD,” or equivalent.

## 4. Evidence
Accessibility results shall be recorded and linked to the applicable requirements.
