## Critical Principle

The public website is an **external information system**, not an extension of VSGH's internal engineering network.

The architecture shall preserve strong separation from:
- PLM
- LIMS
- ERP
- QMS
- IP repositories
- Engineering/R&D repositories
- Sensitive internal identity systems

## Baseline Gate

WEB-040 is the intended architecture/design baseline.

Before moving into production development, the following shall be reviewed:
- Requirements traceability
- System architecture
- Sitemap
- UX
- Design system
- Component architecture
- Page specifications
- Content architecture
- Application/API design
- CI/CD
- Performance
- Security
- Threat model
- Data model
- DNS/TLS/edge
- Integrations
- SEO
- Accessibility
- UAT

## Design Philosophy

The VSGH website shall communicate:

**Advanced Materials + Scientific R&D + Engineering Discipline + Aerospace/Industrial Capability + Circular Resource Intelligence**

without exposing proprietary technical know-how.
