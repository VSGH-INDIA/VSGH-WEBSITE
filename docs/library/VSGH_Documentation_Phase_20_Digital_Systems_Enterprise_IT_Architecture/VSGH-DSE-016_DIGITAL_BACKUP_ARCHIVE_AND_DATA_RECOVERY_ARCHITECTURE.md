# VSGH-DSE-016 — Digital Backup, Archive and Data Recovery Architecture

## 1. Purpose
Define resilient protection of VSGH digital information.

## 2. Scope
Includes:
- Corporate systems
- Engineering data
- Laboratory data
- Manufacturing records
- QMS records
- Financial data
- Source code
- Configuration records

## 3. Backup
Backups shall be:
- Scheduled
- Monitored
- Access-controlled
- Protected from unauthorized alteration
- Periodically tested

## 4. Recovery
Critical systems shall have defined recovery objectives appropriate to business impact.

## 5. Ransomware Resilience
Backup architecture shall prevent compromise of all recovery copies through a single system compromise.

## 6. Archive
Long-term records shall be preserved in controlled archival systems.
